# DW3 – Desenvolvimento Web 3

Este repositório reúne **projetos, exemplos teóricos e exercícios práticos** desenvolvidos durante as aulas da disciplina **Desenvolvimento Web 3 (DW3)**, do **Curso Técnico Integrado em Informática** da **Universidade Tecnológica Federal do Paraná – Campus Campo Mourão (UTFPR-CM)**.

## Conteúdo do Repositório
- Projetos desenvolvidos em sala de aula
- Exemplos teóricos apresentados durante as aulas
- Exercícios práticos para fixação dos conteúdos
- Experimentações com tecnologias web utilizadas na disciplina

## Objetivo
Organizar e documentar o material produzido ao longo da disciplina, servindo como **registro de aprendizado, consulta futura e apoio para estudos em desenvolvimento web**.
